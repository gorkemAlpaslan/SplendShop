# SplendShop

An e-commerce frontend web application built with **React 18**, **Material UI**, **React Bootstrap**, and **Firebase Authentication**.

## Features
- User authentication powered by Firebase
- Product catalog browsing & search
- Shopping cart and checkout flow persisted with `localStorage`

## Tech Stack
- **React 18** (Create React App)
- **Material UI (`@mui/material`)** & **React Bootstrap**
- **Firebase v9** (Authentication)

## Getting Started
```bash
git clone https://github.com/gorkemAlpaslan/SplendShop.git
cd SplendShop
npm install
npm start
```
